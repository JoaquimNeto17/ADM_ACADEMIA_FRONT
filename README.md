🏋️‍♂️ API Academia

Sistema web moderno que simula um painel administrativo de academia, com cadastro, listagem e controle de atletas via CPF.

📌 Sobre o Projeto

O API Academia foi desenvolvido com foco em interface e experiência do usuário, simulando um sistema real de gerenciamento de academias.

A aplicação permite cadastrar atletas, visualizar registros e controlar o status (ativo/inativo), tudo através de uma interface moderna e intuitiva.

💡 Ideal para projetos front-end, portfólio e evolução para sistemas completos com back-end.

🎯 Funcionalidades

✔️ Cadastro de atletas (nome + CPF)
✔️ Máscara automática de CPF (000.000.000-00)
✔️ Definição de status (Ativo/Inativo)
✔️ Listagem dinâmica de usuários
✔️ Edição de registros
✔️ Exclusão de registros
✔️ Interface administrativa moderna
✔️ Design responsivo e intuitivo
